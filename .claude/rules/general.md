# General Project Rules

- Always use software engineering best practices.
- Be strategic with component organization and structure.

## Engineering Standards

- **Paradigm**: Use functional programming patterns; avoid classes where possible.
- **Imports**: Use ES modules (import/export). Destructure imports from common libraries.
- **Error Handling**: Use explicit error boundaries. No "catch-all" empty blocks.
- **Testing**: Follow TDD. Write failing tests before implementation. Avoid mocks for core logic.

## Critical Gotchas

- Always verify type safety before suggesting a commit.
